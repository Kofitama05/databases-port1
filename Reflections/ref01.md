# Reflection 1


## Take-away
From Module 1, I was able to gain knowledge about databases and how SQL can be used to work with data. I know databases are used to store data, and we can access this data using SQL.I learned that SQL can be used to retrieve, filter, insert, and update information in a database. I also learned that it is important to check the results of my queries instead of assuming they are correct.

## What was good?

The SQL island game helped me practice queries such as SELECT, WHERE, AND, LIKE, INSERT, and UPDATE. I had difficulties getting the right results because of incorrect table names and column names. I also learned that results can be affected by case sensitivity; results will differ when I use uppercase or lowercase.

What I enjoyed most was working with SQL Island because it allowed me to practise SQL in an interactive way. I could see how different commands affected the information stored in the database.

I also enjoyed the telemetry task because I was able to use Python to generate machine data, load it into SQLite, and analyse the results using SQL. This helped me understand how databases can be used in practical situations.

## What was difficult?

My challenge was working with the project environment in VS Code and PowerShell. I had to learn how to run Python scripts, work with the database files, and check whether the generated data had been loaded correctly.

## Exploration and show stoppers

The main difficulties I encountered were related to SQL syntax, command-line usage, and setting up the database environment. I was able to work through these problems by checking my commands, running queries again, and verifying the results.

## Interaction with peers and instructors

During this module, most of my learning came from working through the exercises independently and using the course instructions to understand the tasks. I used the available learning materials and practical examples to improve my understanding of SQL and databases.


## How did you verify AI suggestions?

I used AI to help me understand SQL and generate a query for analysing the telemetry data. The prompt asked AI to calculate the average spindle load for each machine using readings taken after 18:00 and to order the machines from the highest average to the lowest. I did not simply accept the generated query. I ran it in SQLite and checked whether it produced the expected results.
AI can be useful for learning and writing SQL, but its suggestions should always be tested and verified. I learned that checking the results and understanding the query are more important than simply copying an answer.

## Help and extra work

I used the course materials and AI assistance to help me understand the tasks, solve problems, and improve my SQL queries. The explanations were valuable because they helped me work through difficulties step by step and understand the purpose of different commands. Overall, Module 1 was a useful learning experience. It helped me develop a better understanding of databases and gave me a foundation for the more advanced tasks in the upcoming modules.
