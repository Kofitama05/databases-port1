# SQL Island — Learning Notes

Official game: https://sql-island.informatik.uni-kl.de/

## 1. What I learned

I learned how to retrieve information from database tables and filter records according to specific conditions. I practised finding inhabitants based on their jobs and states, adding a new inhabitant, and updating the owner of an item. I also learned that SQL queries must use the correct table names, column names, and values to return the expected results.

## 2. SQL commands and patterns I used
SELECT — to retrieve information from tables.
WHERE — to filter records based on conditions.
AND — to combine two conditions in one query.
LIKE — to search for text patterns, such as jobs ending in smith.
INSERT — to add a new inhabitant to the database.
UPDATE — to change the owner of an item.
IS NULL — to find items that do not have an owner

## 3. Database vocabulary
Table: A collection of related data organised into rows and columns, such as the inhabitant table.
Row: One complete record in a table, such as the record for Ernest Perry.
Column: A field describing one type of information, such as name, job, or gold.
Query: An instruction written in SQL to retrieve or change information in a database.

## 4. What surprised me / what is still confusing
I was surprised that searching for butcher and Butcher could produce different results because the values were treated as case-sensitive in the game.
